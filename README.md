# SpaceInvader_Game
🚀🎮 Just Launched: My Own Space Invaders Game! 👾💥

Excited to unveil my retro-style Space Invaders game built entirely with Python and the Pygame library! This project combines creativity with core programming concepts, and it was a lot of fun to bring it to life.

🔧 Tech Highlights
🐍 Developed with Python
🕹️ Built using Pygame for real-time rendering and controls
🎨 Custom-designed graphics (player, enemies, bullets, background)
🔊 Integrated sound effects with Pygame Mixer
🧠 Game logic: player movement, enemy AI, shooting, and collision detection
🏁 Dynamic score tracking, win/lose states
🎯 Stylish UI with Restart/Exit buttons and interactive feedback

This project helped me solidify my understanding of OOP, event-driven programming, and game mechanics, while sparking creativity through design and interaction.
